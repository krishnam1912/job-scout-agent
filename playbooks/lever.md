# Lever playbook (site mechanics only)

- Job IDs are UUIDs; pages at `jobs.lever.co/<token>/<id>`.
- Short single-page form: resume, links, a few custom questions.
- Some forms have **no visa/sponsorship question** even for roles abroad: note it and draft a recruiter note for the user to send.
- hCaptcha or account prompt: skip and list.
