# Greenhouse playbook (site mechanics only)

- Job pages: `boards.greenhouse.io/<token>/jobs/<id>`, `job-boards.greenhouse.io/<token>/jobs/<id>`, or a company page with `?gh_jid=<id>`.
- Fill in batched actions; upload `profile/resume.pdf`; answers from `profile/apply-kit.md`.
- Many boards email an **8-character security code** after the form is filled; it goes into one box per character at the bottom. Read it from email only if the batch approval allows it.
- Some companies show **reCAPTCHA** (seen on Okta): skip and list.
- Some add an **NDA / candidate agreement** step (seen on Rubrik). Check every field before clicking near Submit; stray clicks can submit early.
- Some roles **require a cover letter** (seen on some Stripe roles). If none exists, skip and list; draft one only from profile facts.
- If your college isn't in a school dropdown, pick "Other".
- Leave optional marketing consents unticked.
