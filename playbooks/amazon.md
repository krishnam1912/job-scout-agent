# Amazon playbook (amazon.jobs, site mechanics only)

- Job page: `https://www.amazon.jobs/en/jobs/<id>/<slug>`. The scanner uses the same `<id>`.
- Needs the user's amazon.jobs sign-in. If a password prompt appears, skip and list.
- Confirm each submission on the amazon.jobs dashboard.
- Experience questions come as bands (e.g. "3 to <4 years"); answer from `profile/apply-kit.md`.
- If asked about earlier Amazon applications, disclose them.
- International roles: education page → job-specific questions → eligibility (sponsorship / government employment) → acknowledge → optional "other jobs" consent (default decline).
- Amazon often posts several identical reqs for one role; the scanner keeps only the newest.
